        JavaScript Options

        Option Value Default Description
        group String '' The group
        animation String, Boolean slide Animation mode (slide, fade, delayed-fade, false).
        duration String|Boolean 250 Animation duration in milliseconds.
        threshold Number 10 Mouse move threshold before dragging starts.
        cls-item String gls-sortable-item The item class.
        cls-placeholder String gls-sortable-placeholder The placeholder class.
        cls-drag String gls-sortable-drag The ghost class.
        cls-drag-state String gls-sortable-dragging The body's dragging class.
        cls-base String gls-sortable The list's class.
        cls-no-drag String gls-sortable-nodrag Prevent dragging on elements with this class.
        cls-empty String gls-sortable-empty The empty list class.
        cls-custom String '' The ghost's custom class.
        handle String false The handle selector.
